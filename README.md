# Intent-to-UI
Intent to UI — an LLM-powered UI runtime for conversational interfaces.

Intent to UI is an LLM UI runtime that allows large language models to invoke predefined UI components across web and mobile.
A runtime layer that allows LLMs to select and invoke predefined UI components across web and mobile.

LLM (UI JSON)
   ↓
UI Parser
   ↓
Message bubble + UI Components
